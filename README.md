# Hardware & Embedded Systems Portfolio

Welcome to my central repository for FPGA design, RTL development, and low-level embedded systems projects.

I am a pre-final year Electronic & Computer Engineering student at Trinity College Dublin (Integrated Master's) specializing in digital logic, semiconductor concepts, synthesizable FSM design, and hardware-software integration.

## Technical Highlights
* **FPGA / RTL Design:** Experience with Xilinx Artix-7 (BASYS3), Vivado, synthesizable FSMs, timing constraints, Vivado ILA, and real-time signal processing.
* **Embedded Systems:** Bare-metal C/C++ development (ATmega, ARM), ARM Assembly, SPI/I2C/UART/HTTP/MQTT protocols, custom PCB design, and real-time control logic.
* **Languages & Tools:** Verilog, VHDL, Embedded C/C++, Python, Vivado, EagleCAD, LTSpice, Linux CLI, Git, MySQL, AutoCAD.

## 📌 Featured Projects

* **FPGA Real-Time Signal Processing:** Implemented synthesizable multi-state FSMs in Verilog targeting the Xilinx Artix-7 (BASYS3) with static timing analysis to eliminate latency bottlenecks.
* **Multi-Sensor Embedded Platform & Graphics Engine (MAC):** Designed an ATmega328P-based gaming console driven by multi-sensor inputs (ultrasonic, film pressure sensors, and potentiometers). Engineered a custom C++ pseudo-3D perspective rendering pipeline on a 128x64 OLED (4-wire SPI) using fixed-point math and zero dynamic memory allocation (~50 FPS).
